# Product tour

CIEL Lab is organized around the lifecycle of a terminology change.

## Dashboard

Start with release health and coverage: active and retired concepts, mappings,
locales, translated names, change trends, and source coverage.

## Quality assurance

The QA menu contains focused checks:

- **Required Class Mappings** finds missing mappings for selected concept
  classes and target terminologies.
- **Retired Codes** finds CIEL mappings whose external code is retired.
- **Display Issues** turns display-name findings into reviewable corrections.
- **Bulk Validation** runs the complete deterministic rule set and preserves a
  report that can become a worklist.

## Release

The Release page compares CIEL HEAD with the latest release, checks the QA gate,
and coordinates release creation and artifacts.

## Tools

- **Concept Manager** is the main place to find, inspect, create, copy, and edit
  CIEL concepts.
- **Code Search** searches CIEL and indexed external terminologies by text,
  semantics, or exact code.
- **Translation** imports and reviews suggested translated names.

## Settings and administration

Settings contains user preferences, the encrypted personal OCL token, password
management, and optional MCP credentials. Administrators can approve and manage
accounts from **Admin → Users**.

## Public Explore

Explore provides a public bridge across CIEL and supported reference
terminologies. It helps a reader discover related codes; it is not a promise of
lossless code conversion or clinical equivalence.
