# Display Issues

Display Issues turns name-related bulk-validation findings into a focused
review workflow.

## What the page emphasizes

The fully specified name (FSN) is highlighted because an incorrect display or
casing choice can propagate to downstream exports. The page can show approved
fixes and apply them to OCL with the current user's credentials.

## Review workflow

1. Open a recent Bulk Validation report.
2. Filter to display or name findings.
3. Open the affected concept.
4. Compare the preferred name, FSN, synonyms, locale, and concept class.
5. Apply the smallest correction that satisfies the rule.
6. Save with an explanatory comment when appropriate.
7. rerun the finding or the full report.

Do not normalize names solely for visual consistency. Casing exceptions,
acronyms, organisms, drug names, and terminology-specific conventions may be
intentional. The validation assets generated by `ciel-scripts` provide a
repeatable baseline, but a human remains responsible for the final decision.
